# Agentic Awesome Skills (AAS)

This is the installed **agentic-awesome-skills** library containing 2,900+ modular agent skills, playbooks, and execution templates.

## Catalog Overview
- Total Skills: 2,900+
- Root Directory: `C:\Users\ngvu2\.gemini\config\skills\agentic-awesome-skills\skills`
- Catalog Index: `skills_index.json` and `CATALOG.md`

## Key Capabilities
1. **Frontend & UI/UX Design**: Responsive layouts, modern typography, glassmorphism, micro-interactions, accessibility (WCAG).
2. **Backend & Architecture**: High-throughput APIs, database indexing, caching strategies, offline-first sync.
3. **Quality & Security**: Automated test suites, vulnerability scans, linting, error boundaries.
4. **Agent Orchestration**: Dynamic skill discovery via `aas-discover`, stack composition via `aas-compose-stack`.

## How to Activate Specific Skills
When a task requires a specific capability from the catalog:
1. Search `skills_index.json` or browse `skills/<skill_name>/SKILL.md`.
2. Read the corresponding `SKILL.md` to follow its prescriptive workflow and prompt guidelines.
